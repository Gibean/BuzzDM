Presentación académica del proyecto

Recorrido explicativo sobre la arquitectura, el diseño de la base de datos y la operación en tiempo real de los módulos de inventario, pedidos y compras del ERP.

Muchas empresas en crecimiento enfrentan el mismo problema. Lo que registra el sistema no refleja lo que realmente hay en el almacén. Pedidos sin stock, compras duplicadas, datos dispersos en hojas de cálculo que nadie controla. Bust Data Manager es una herramienta útil para resolver eso. Es un sistema ERP orientado a la gestión de inventario, ventas, clientes y logística. El backend está construido en PHP 8.1 con María d b como motor de base de datos. El frontend usa HTML 5, Bootstrap 5.3 y JavaScript sin frameworks pesados, lo que mantiene la carga rápida y el mantenimiento simple. La arquitectura sigue un patrón derivado de MVC. Cada módulo tiene 3 responsabilidades claramente separadas. El controller recibe la petición HTTP. El service aplica la lógica de negocio y el repository accede a la base de datos. Esto hace que el sistema sea mantenible extensible, sin afectar el resto del código. El resultado son 26 endpoints documentados bajo Open API 3.0, consultables directamente desde el Swager UI integrado. Boost Data Manager está organizado en 4 grupos funcionales. El grupo de productos cubre el inventario completo, productos físicos, servicios y kits organizados por categorías, marcas y almacenes con sus respectivos proveedores. El grupo de operaciones es donde ocurre el trabajo diario, gestión de clientes, creación de pedidos, control de envíos, entradas de mercancía, requisiciones de compra y transferencias entre almacenes. El grupo de herramientas incluye un tablero de tareas tipo Kanban y la importación masiva de datos desde Excel, y el grupo de sistema cubre la administración de usuarios, generación de reportes, backups automáticos y configuración general. Vemos 2 módulos en acción. El módulo de inventario gestiona el stock bajo el modelo de costo promedio ponderado. Cada vez que entra mercancía, el sistema recalcula automáticamente el costo unitario promedio. Esto simplifica la valoración para operaciones de mercancía general. Cada entrada de mercancía pasa por un ciclo de vida controlada, borrador, confirmado o anulado. El momento crítico es la confirmación. Un trigger SQL suma automáticamente las cantidades al almacén correspondiente. Si hay un error, otro trigger revierte todo. No hay movimiento sin respaldo de auditoría, ninguno, y el sistema no solo mueve stock, lo clasifica en tiempo real. Cada producto tiene un estado que se actualiza solo, verde si hay suficiente, amarillo si está bajo el mínimo, rojo si se agotó. La seguridad no es un módulo separado en boss data, está en el núcleo del sistema. El control de acceso es por roles, administrador, supervisor y operador, con permisos definidos en base de datos por módulo, no en código. La autenticación usa cifrado de crip. Al 10º intento fallido, la cuenta se bloquea automáticamente y el administrador recibe una notificación inmediata. Las cuentas administrativas requieren doble factor de autenticación con Google Authenticator, implementado de forma nativa sin servicios externos. A nivel de infraestructura, todas las consultas a base de datos están parametrizadas para prevenir inyección SQL. Boost Data Manager elimina trabajo manual. 3 automatizaciones que lo demuestran. 1º, cuando un producto cae bajo su stock mínimo, el sistema genera la alerta al administrador sin intervención humana. Ningún producto se agota sin aviso previo. 2º, y esta es la más impactante operativamente, las requisiciones inteligentes. Un clic en auto stock consulta todos los productos bajo su mínimo y rellena la solicitud de compra con las cantidades necesarias y el proveedor con mejor precio histórico. Lo que antes tomaba tiempo, toma un clic. 3º, 6 triggers SQL activos automatizan la actualización de stock, el registro de movimientos y el log de auditoría en cada operación. Entre otras automatizaciones, backups diarios automáticos e importación masiva desde Excel con validación fila por fila. La base de datos tiene 30 tablas y 16 vistas SQL, que precalculan los datos más consultados, inventario crítico, top de productos vendidos, historial de importaciones. La integridad referencial está garantizada mediante foreign keys, y el soft delete asegura que ningún registro maestro se elimine físicamente. Todo tiene historial. El sistema está validado para más de 100000 productos, 10000 pedidos mensuales y múltiples almacenes con ubicaciones internas, y los 26 endpoints documentados en Open API 3.0 permiten que cualquier frontend futuro, tienda en línea, aplicación móvil, se integre sin modificar el backend. Bus Data Manager está en producción en bus data manager punto com como sistema de gestión de pedidos para la librería Chiqui en El Tigre, estado Anzoategui. Es un sistema completo pensado para pequeñas y medianas empresas. Inventario, ventas, logística, seguridad y automatización.
