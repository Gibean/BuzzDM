Guía de Contribución con Git

Buzz Data Manager es un proyecto académico de código abierto. Si deseas colaborar con correcciones de errores, optimizaciones de consultas o mejoras en la interfaz, sigue este flujo estándar de trabajo con Git.

1 Clonar el repositorio y configurar el entorno

Asegúrate de tener Git instalado y un entorno local con PHP 8.x y MySQL (como XAMPP). Clona el repositorio oficial:

# Clonar repositorio localmente
git clone https://github.com/tu-usuario/BuzzDM.git
cd BuzzDM

2 Crear una rama para tu mejora (Feature Branch)

Nunca hagas commits directos sobre la rama main. Crea una rama descriptiva para tu tarea:

# Asegúrate de estar actualizado con main
git checkout main
git pull origin main

# Crear y cambiar a tu nueva rama
git checkout -b feature/optimizacion-inventario

3 Convención de Mensajes de Commit (Conventional Commits)

Seguimos el estándar de Conventional Commits en español o inglés técnico:

feat(inventario): agregar filtro rápido por categoría en listado
fix(pedidos): corregir validación de stock al despachar orden
docs(readme): actualizar requisitos mínimos de PHP y MySQL
refactor(db): optimizar consulta en search_api.php

Para registrar tus cambios:

git add .
git commit -m "feat(inventario): agregar filtro rápido por categoría"

4 Publicar la rama y abrir Pull Request (PR)

Sube tu rama a tu repositorio remoto en GitHub:

git push -u origin feature/optimizacion-inventario

Luego dirígete a GitHub y haz clic en "Compare & pull request". Describe los cambios realizados, el problema que resuelve y las pruebas ejecutadas.
