Feat(UI): Mejoras responsivas en Login y módulo de Envíos (v1.4.2)

Módulos Afectados:
- Módulo de Envíos (`envios.js`, `ShipmentRepository.php`)
- Autenticación / Login (`login.php`)
- Landing Page (`landing.js`)

Descripción de Cambios:
- **Vista de Envíos**: Rediseño responsivo de las tarjetas de envío para móviles. Se agregó soporte para conversión en tiempo real de USD a VES usando la API de Tasa BCV.
- **Filtro de Envíos**: Corregida la consulta en `ShipmentRepository.php` para excluir pedidos con borrado lógico (`deleted_at`), asegurando consistencia con los subtotales del módulo de Pedidos.
- **Login Frontend**: Ajustes CSS para la vista móvil, incrementando legibilidad de inputs y botón, además de asignar fondo transparente para revelar la animación de hexágonos del sistema.
- **Landing Page**: Correcciones menores en el carrusel/animaciones de `landing.js`.
